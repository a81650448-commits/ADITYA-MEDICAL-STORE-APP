# Aditya Medical Store App

A separate Android-first customer app project for Aditya Medical Store.

## Safety boundary
- This repository is separate from the existing `seema-medical-store` website.
- The existing website and Admin Panel are not modified by this project.
- Live Supabase integration will be added only after the app UI and test flows are validated.

## Planned customer features
- Home and medicine categories
- Medicine search
- Cart
- Customer login/signup
- Online medicine orders
- My Orders and tracking
- Store contact and Google Maps location
- UPI payment integration

## Current stage
Phase 1: standalone app foundation and customer UI prototype.
